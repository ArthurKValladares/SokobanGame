01

Current verdict

Next program: close the visual/performance evidence gap, then implement persistent renderables and frustum culling. The completed SSAO path—view-space reconstruction, scene-unit sampling, half-resolution storage, bilateral upsampling and ambient-only composition—is now a renderer invariant.

What is strong now

The foundation is no longer the blocker

The renderer has a real camera and world transforms, instanced tiles, distinct opaque paths, an HDR scene target, cgltf validation, tangents and UV1, a GPU material buffer, and Cook-Torrance GGX. These are baseline invariants.

What comes next

Measure, persist, then cull

Capture representative post-tonemap/material images and AO timings across render scales. Then separate stable renderables and bounds from per-frame state so the existing frustum math can remove invisible work before Vulkan recording.

What not to overbuild

No per-material descriptor sets

Draws and materials select SSBO entries by index, while the texture heap lives in set 1. Preserve that bindless direction; do not introduce per-material or per-draw sets.

Safety model

Fence-safe sets before update-after-bind

FrameDescriptorSync already updates only the set belonging to a completed frame. Preserve that model. Add update-after-bind later only if concurrent descriptor mutation becomes necessary and measured.

03

Design corrections that change the plan

Vulkan contract

Descriptor indexing is core

The engine requires Vulkan 1.3, so descriptor indexing should be queried through VkPhysicalDeviceVulkan12Features. Do not add an extension-name requirement that excludes conforming core implementations.

Layout rule

The texture binding must move

A variable descriptor-count binding must be the highest binding in its set. The heap is now the only binding in set 1; set 0 retains scene resources through binding 12.

Synchronization

Update-after-bind is optional

Per-frame descriptor generations avoid rewriting in-flight sets. One texture set per frame is updated only after completion; update-after-bind and partially-bound access are not required.

Content architecture

Manifest parsing stays pure

AssetManifest::parse still does no filesystem work. The explicit-root content pipeline now resolves inspected glTF sources, deduplicates them by source plus interpretation and stages external dependencies.

Image sources

A path is not enough

External URIs, GLB buffer-view images and supported data URIs share one source variant. Color and combined-sampler interpretation are part of identity so current descriptors remain unambiguous.

Shader boundary

UI split before map sampling — complete

The scene fragment shader is now 669 lines after mapped PBR and alpha-policy work and still contains no font, title-art, UI-texture or rounded scene-image branches. The 93-line UI fragment module retains those modes after tonemapping.

Color and AO invariant: base-color/emissive maps are sRGB; normal/MR/occlusion are linear. Material occlusion scales the ambient contribution before the ambient ratio is written; SSAO then composes against that reduced share. Neither affects direct, specular or emissive terms. The hardware sRGB attachment remains the frame's only output encode.

7PBR maps

Sample maps one type at a time

Complete
7.1
Metallic-roughness — complete

The linear packed map reads G roughness and B metallic, multiplies authored factors, supports UV0/UV1 and scrolling, and feeds the direct plus ambient material partition. CPU-reference tests pin the channel and clamp math.

7.2
Normal — complete

The shader re-orthogonalizes world-space TBN, applies linear normal maps and scale, supports UV0/UV1 plus scrolling, and reverses the final mapped normal on double-sided back faces. CPU-reference and synthetic authored/derived tangent fixtures cover the contract.

7.3
Emissive — complete

The sRGB-backed map samples as linear RGB, multiplies the factor, supports UV0/UV1 plus scrolling and adds unclamped HDR color. Its alpha is ignored; it stays outside the ambient numerator while remaining in total light so SSAO preserves self-emission. CPU-reference tests pin the contract.

7.4
Occlusion — complete

The linear map reads R, interpolates by clamped strength, supports UV0/UV1 plus scrolling and scales diffuse plus metallic ambient fill only. The already-reduced ambient enters both sides of the scene mask, so material and screen-space AO compose without touching direct, specular or emissive light. CPU-reference tests pin the contract.

7.5
Alpha and mirror audit — complete

A tested material policy splits mixed meshes across the existing opaque/blended pipelines, sorts translucent models farthest first, applies MASK to factor × texture alpha, and honors per-material sidedness without new pipeline permutations. OPAQUE ignores authored opacity; BLEND multiplies it by instance alpha. Mirror energy consumes only base-color factor/texture RGB, UV selection and scrolling—never material alpha or the PBR lighting maps.

Gate: all 16 shaders compile; the focused CPU policy has 55 passing checks, scene preparation has 1,545, the embedded GLB fixture covers maps/UVs/MASK/double-sided transport, production glTF content exercises BLEND, and all 68 Debug suites pass. Manual appearance capture remains in 0.1; MASK shadow cutouts remain a separate depth-only-shadow limitation.

The exact scene projection and inverse round-trip copied Vulkan depth into view space. Position derivatives provide camera-facing geometric normals; twelve rotated hemisphere samples use a 0.45 scene-unit radius, 0.025-unit bias and Euclidean range rejection.

05

Remaining work after the material program

Visibility

S2 then T4

Persistent renderables with stable bounds are the prerequisite. The existing Frustum/Aabb math is ready; do not add an occlusion system before ordinary frustum culling is measured.

Memory and texture format

V2 then A2

Generalize allocation and image creation before KTX2/BC7, mip chains and streaming make allocation patterns more complex.

Residency

A3 remainder

The system already has requirements, budgets and eviction. Replace idle waits with explicit retirement and add mips/LOD; do not rewrite the scheduler from zero.

Conditional architecture

S1, S3 and F5

Fixed tick needs continuous gameplay physics. A task graph needs a measured scheduling problem. An RHI needs a second backend or platform. Until then, these are not priority work.
